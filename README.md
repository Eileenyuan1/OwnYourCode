# OwnYourCode

OwnYourCode helps students learn and explain their own GitHub projects through AI-guided lessons and mock interviews grounded in the real code.

**Team:** [Eileenyuan1](https://github.com/Eileenyuan1) · [RipZou](https://github.com/RipZou)

## Local setup

```bash
npm ci
npm run dev
```

## Checks

```bash
npm run lint
```
